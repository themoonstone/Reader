## 发现与修正

1. README 仍写“没有 Docker、真实认证待配置”，与 Mac 真实登录及服务器私有预部署不符：同步当前事实；本地离线可用与 cloud 必须联网分别说明。
2. 07/15 和 Feature List 的部分状态过时，03 仍把 v0.6 写作当前基线：同步 v0.8 和 16/17 的证据，保留历史验收的适用时间。
3. 缺少 COS 建桶、受限 CAM 权限与两种密码分工：新增 18，给出用户先做的具体配置。
4. 现有生产 Compose 要求域名/认证/应用与备份齐备，不能用于只推进备份：新增独立 backup Compose 的合同，引用已有卷，不启动公网代理或正式应用。
5. preview 与生产使用固定 restic host/tag，若共用仓库会参与同组清理：要求分开仓库前缀；切正式卷后重新验收。
6. 原“每日 7 份/每周 4 份”容易误解为固定 11 个文件；按真实 restic 保留周期及作业完成后休眠说明。默认 check 不等于完整读回，新增 read-data 与恢复核对步骤。
7. 同机快照、异地密文、恢复后的隔离库和 Mac 正式库边界补齐；域名不影响备份，但 Secure Cookie 登录仍依赖 HTTPS。
8. 加入剩余缺口：真实 COS/恢复/调度/费用/通知、正式库迁移、HTTPS 和手机验收均不能提前标完成；空库测试也不能证明真实库已被备份。
