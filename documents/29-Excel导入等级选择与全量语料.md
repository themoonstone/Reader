# Excel 导入等级选择与全量语料

日期：2026-11-03。状态：L1–L5 已完成实现、验收与正式发布；真实 iPhone Safari 完整任务仍待用户验收。

用户希望将 Counselling for Toads 第 1–16 章的全部语料入库，包含 P1/P2/P3，并明确授权同步修改网站。本文是对 [28](28-Excel多Sheet选择导入开发设计与验收.md) 的增量：页选择和等级选择共同决定导入范围；旧版“仅 P1”的验收记录保留为历史。

## 1. 需求与边界

1. 新 UI 默认只选 P1；提供 P1/P2/P3 独立勾选、全部等级和清空，至少选一个等级才可检查。等级是收藏优先级，不是自动复习任务。
2. 三种受支持的模板均支持等级选择。标准 15 列不变，导入时保留每行原等级，不把 P2/P3 伪装成 P1。清点和逐行校验仍覆盖所有已选页的所有等级，包括被过滤的行，原安全上限不变。
3. 预览分别展示各等级原始行数、所选等级、按等级排除的行数、文件内副本、唯一可选语境和实际选中语境。空结果不能创建空来源。
4. 文件、页或等级改变时，旧内容预览、分组决策、差异和确认均失效；乱序响应不能恢复旧范围。提交时锁定范围。等级改变不必重新上传或清点文件。导入后“查看本书的表达”清空等级筛选；即使单选 P2 也可能追加到保持 P3 的已有义项，不能按 P2 筛选而隐藏刚导入的内容。
5. 新请求沿 `selected-sheets-v1` 增加 `priorities`（非空、不重复的 P1/P2/P3 数组），服务端按 P1/P2/P3 规范顺序处理并纳入签名内容预览。差异证明继续绑定完整内容预览；跨等级的旧差异证明不可提交。省略该字段时仍为 P1；无选页 mode 的旧接口仍只允许 P1，拒绝隐式传入等级选择。
6. 同词、同中文义项的多等级接触可归同一分组，每行 Context 保留原等级。新建合并义项的 Expression 使用该组最高优先级（P1 高于 P2 高于 P3），与 Sheet/行顺序无关；逐行新建按各自等级。复用任何等级的已有有效义项都保留该义项个人等级，不静默升级/降级。旧模式继续执行原 P1 约束。
7. 同一本书先导 P1 再导全部时，旧 P1 重复跳过，补充缺失 P2/P3；原库中本次未出现的内容继续保留。修订默认保留旧值，不自动覆盖个人笔记、已有表达等级或 Review 历史。原表的语境等级变更会明确列入差异；采用时先保存快照，仅更改 Context 等级，已有 Expression 等级不随之修改。
8. Review 入口、候选资格、20 个活跃池上限、配额和历史保持现状：收藏不会自动入池，P3 不因批量入库获得复习资格。不做数据库 schema 或 JSON 备份格式迁移。

## 2. 全量文件合同

从原表 16 个章节页取 628 条语境：P1 201、P2 310、P3 117；不重复复制 P1 汇总页。按章节保留 Sheet、统一书名 `Counselling for Toads`，保留标准 15 列；原文只移除 `【】`，真实连续高亮、原页码/释义和备注保留。原文均为“待核对”，不冒称已核实；新增例句等缺失内容不编造。新版第 6 章与旧版材料不同，重导应看差异，不能承诺旧章节全为重复。
