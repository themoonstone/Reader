## 1. 已确认的目标与取舍

用户明确不需要所有收藏按期复习，希望可持续使用。收藏库用于积累证据，复习池用于挑选近期愿意练习的表达；二者分开。P1 是学习意愿标签，不是自动加入复习的开关。

本设计取代旧版“P1/P2 入库即调度、Forgot 10 分钟重试、同会话最多两次、固定 3/7 天循环”的规则。可以存在已具备出题资格的收藏而永远不加入池，也允许池中表达长时间不练；不补课、不产生多次欠账，不推断已掌握。

用户已确认上述产品原则。下表数值是本次开发建议基线，供实施和测试使用，可后续显式调整；不是用户逐个指定的数值，也不是经记忆实验验证的算法。没有日历提醒、推送、每日打卡或自动增加学习量。

### 4.1 复习池与材料资格

表达池状态独立于 P1/P2/P3 和 active/archived/deleted。未加入时可没有池行；已有行移出后保留 `not_joined`，用于保留首次出题和历史，不能通过移出重进规避限制。

加入和恢复仅接受 active、P1/P2、至少一条当前阶段合格 Context 的 Expression。批量选择仅在专用复习池选择页提供，显示所选义项与总数，整批容量/资格校验通过才提交；不扩展为通用批量编辑。池满时明确提示先暂停或移出，不静默替换已有项。

暂停/移出保留收藏、反馈、间隔阶段和首次出题事实。手动恢复时旧词保留间隔阶段，有反馈者 `eligible_after=max(now, 原 eligible_after)`，尚无反馈冷却者保持空值，不能跳过尚在冷却的间隔；从未出题者仍需新引入名额。恢复不补算错过次数。

Expression 改 P3、归档、删除或失去全部合格语境时，活跃池条目事务内自动暂停，记录原因；当前卡失效。恢复表达/改回 P1/P2/补齐语境不会自动恢复池，必须用户显式恢复。Source 归档继续保留现有证据，不自动暂停其表达；语境改归属后不得把旧表达的池状态或调度迁移到目标表达。

### 4.2 题面和答案

RV-A 的 Recognition：表达须有义项、至少一条 active Context、非空语境释义，以及用户保存的真实原句或明确采纳的正确句。题面单独展示 term，附对应句子；不要求 term 必须逐字出现在句中，不猜词形、不伪造高亮。写作纠正优先采用用户保存的 corrected_sentence，缺正确句则该条纠正语境不能出题。不能用 Excel 的学习改写 K 列充当原文。

答案揭晓前不显示义项、语境释义、导入释义/改写、纠正目标等答案字段；不提前把答案放进 DOM、无障碍名称或 HTML 属性。揭晓后分开显示表达义项和该语境释义，沿用导入的中英文语言标记。自评不是自动判题，不计算正确率或“已掌握”。

RV-B 的 Recall 需要有效目标区间，采用原始学习句的 JavaScript UTF-16 索引，起点包含/终点不含，`sentence.slice(start,end)===target_surface`。不能按规范化文本的索引切原句。多次出现须换合适语境或修正材料；若另一处仍泄漏目标，首版不生成此题，不自动做多处挖空。不连续片段或词形未确认降级 Recognition。

Writing Recall 使用明确 intended_meaning 作提示；答案为已保存的正确句和目标。提示含目标英语时拒绝；不能把原错误片段的出现位置当作改进表达的区间。题型缺失可降级，不能自动编造中文意图或补齐原句。P2 始终只出 Recognition。RV-B 在合格时优先 Writing Recall → Recall → Recognition。

同模式语境优先选择从未展示的记录，再按上次展示最早、created_at、ID 选择；展示事实由卡片记录提供，跳过也轮换语境。所有题型共用每表达每会话一次限制。

### 4.3 发卡、反馈和间隔

每次新发卡按以下顺序执行，规则版本保存为 `low-pressure-v1`：

1. 确认本机请求、库 generation、会话租约和版本；先处理同 request_id 的已成功重放。
2. 刷新时间/状态。已暂停、结束或时间用完时不发卡；本轮 issued_count 已达 card_limit 时不发下一张。
3. 只取手动加入且当前合格的 active 池条目，排除本会话已展示的 Expression。
4. 先选已首次出题且冷却结束的旧表达，按 last_presented_at 最早、P1 优先、加入时间、ID 排序。优先级只是并列决胜，不使 P2 长期排在所有 P1 后面。
5. 没有旧候选时，可选尚未首次出题的新表达，但须同时有本轮和当日新名额；按 P1、加入时间、ID 排序。上限不是必须完成的数量。
6. 原子创建稳定 card_id、快照、更新展示时间/首次引入事实及计数，然后返回题面。无候选则结束，剩余时间不强行填卡；冷却中的旧表达不提前填空。

每个表达无论间隔过去多久只占一个候选，不按错过的天数生成多个任务。最坏情况下候选仍受活跃池 20 项限制；表达库数量增加不会自动增加这个池。重复开新会话是用户主动练习，允许继续练已具资格的不同轮内容，但新引入仍受当日总限额。

反馈必须在揭晓之后提交，使用服务端接受时刻计算，保存 stage 前后值和参数版本：

- 初始 stage=0。`rememberIntervals=[3,7,14,30,60,90]`（天）。
- 记得：冷却为 `rememberIntervals[oldStage]`，新 stage 为 `min(oldStage+1,5)`。
- 有点难：新 stage 为 `max(oldStage-1,0)`，冷却为 `max(1,floor(rememberIntervals[newStage]/2))` 天。
- 忘了：新 stage=0，冷却 1 天。本轮不再次出现，不要求练到通过。
- 不揭晓、跳过、失效或退出：不改 stage/eligible_after；不生成 ReviewRecord。跳过仍消耗已展示卡额，新卡首次引入名额也不退回。

例：从未练过的表达第一次“记得”后 3 天可选，第二次“记得”后 7 天，再到 14 天；“忘了”最早下一天可选。数周未打开只影响可选资格，不增加卡量或惩罚。

### 4.4 会话时间与结束

首页默认 10 分钟/10 张/最多 3 个新表达，可改参数，显示“最多”，不显示“今日必须”。会话首页仅展示池中数量/暂停数量、设置和开始/继续入口；不显示到期或逾期总数。首次空池提供“选择近期想练的表达”，不替用户自动挑选整书。

第 10 张（假设 card_limit=10）可以揭晓并提交一次反馈，之后结束；不能在发出最后一张时先锁死其反馈。时间用完则立即停止新反馈与下一题，保留当前卡可查看已揭晓内容；未揭晓的当前卡允许只读揭晓，不生成反馈、不改变调度。

计时以可见且 running 的前台时长为准。暂停、切后台、睡眠/锁屏、网络断开和租约到期均停止练习；恢复不补算后台时间。浏览器事件无法精确界定异常退出/系统睡眠时刻时，只承诺恢复最近成功保存点，不声称毫秒精确。

客户端每 5 秒以及 reveal/feedback/skip/end 前提交心跳；服务端只累计非负且不大于 min(5 秒、距上次接受时刻) 的前台增量，超租约间隔直接暂停、不补时。前端本地计时到限立即禁用反馈；服务端在同一反馈事务内先累计本次增量，再判定预算，防止越界反馈。正常在线心跳时通常只有最后一个 5 秒周期尚未持久化；断网/系统异常可能有更长不确定区间，恢复以最近成功点为准，不承诺最多仅丢 5 秒。不可把离线停留误报成已练。

时间/卡额到达、手动结束或无候选均只结束本轮。显示本次有效时长、已展示卡数、实际反馈数和反馈分布；不显示“完成率”“清零”“记忆率”。可以未用满预算结束。

## 5. 数据设计（RV-A 已建表）

RV-A 已实现数据库 schema 2→3，保留既存四张业务表和 workspace_meta，增加以下四表。字段名为当前 RV-A 开发合同，后续变更须同步备份和验收，不直接把 PRD 领域字段当成当前数据库已有字段。

| 表 | 最小字段与约束 |
|---|---|
| review_entries | id、expression_id UNIQUE、state(not_joined/active/paused)、pause_reason、stage 0–5、eligible_after、first_presented_at、first_presented_local_date/timezone、last_presented_at、last_reviewed_at、version、last_pool_operation_id、created_at/updated_at；软状态，不删除反馈历史 |
| review_sessions | id、start_request_id UNIQUE、state、budget_seconds、card_limit、new_limit、active_elapsed_ms、issued_count、introduced_count、current_card_id、policy_version及参数快照、version、started_at/ended_at、end_reason、last_checkpoint_at；最多一个非 ended 会话 |
| review_cards | id、session_id、entry_id、expression_id/context_id、issue_request_id UNIQUE、review_type、state(shown/revealed/answered/skipped/invalidated)、题面/答案/来源快照、表达/语境/来源/池版本、is_first_presentation、展示本地日期/时区、version、created_at/revealed_at；UNIQUE(session_id,expression_id) |
| review_records | id、card_id UNIQUE、session_id、entry_id、original_expression_id/context_id、result、reviewed_at、前后 stage/eligible_after、policy_version、题面/答案快照；反馈事实不可编辑 |

每日首次引入数量从首次发卡事实计算，不能只依赖可被清空的前端计数。阶段上限、池容量、日期配额均在发卡/加入事务内检查，双窗口不能分别占满两次。读取来源/语境使用当前实体；历史展示使用保存时快照。

运行态租约 token 不纳入业务备份：用独立运行态记录保存 owner_tab、token、lease_version、expires_at，服务重启后清空，持久会话按安全暂停状态供显式继续。不能把 secret 放 NEXT_PUBLIC、日志或 JSON。暂停会话仍占唯一未结束会话位置，开始新的须先显式结束旧会话。

### 5.1 事务与幂等

- 加入/暂停/移出池：版本、容量、资格和条目更新为同一事务；批量加入全成或全败。请求带 operation_id 和各条目预期版本（不存在为 0），条目记录 last_pool_operation_id；相同已成功操作重放不再次激活或占位，旧操作遇到后续暂停/移出时返回冲突，不能恢复过期用户意图。
- 发卡：同 issue_request_id 重放返回同 card_id，不再扣卡额或新额度。有未解决当前卡时，不接受不同 ID 的重复发卡。
- 揭晓：持久状态幂等；重复揭晓不扣卡。时间结束后的只读揭晓仍须校验库与卡版本。
- 反馈：同 card_id 已有同结果记录则返回原结果；不同结果冲突 409。新反馈需版本/租约/卡资格/时间校验，原子插入记录与更新池/卡/会话；失败无半成品。
- 跳过：幂等改变当前卡状态和会话版本，保持调度；跳过和反馈竞争只能一个成功。
- 已成功请求重放仍须通过 generation 与请求身份范围检查，不能把旧库响应写进恢复后的库。幂等命中不重复累计时间。

### 5.2 API

全部沿用当前本机 Host/Origin、JSON 请求限额和 `X-ReadWords-Generation`；会话写接口带 session_version，卡动作另带 card_version；池动作带 entry_version，租约带 lease_version/token。运行态租约约束适用于会话写入，池操作无需租约；预算结束后的只读揭晓按下述例外处理。请求字数保持普通写入限额，备份端点维持独立 50 MiB 规则。

| API | 行为 |
|---|---|
| GET /api/review/pool | 当前条目和容量，不输出欠账总数；未加入候选使用专用分页/筛选，不加载整库所有语境 |
| POST /api/review/pool | operation_id + 明确选中的 expression_ids / expected_versions，事务加入 |
| PATCH /api/review/pool/:id | version + pause/resume/remove，保留历史 |
| GET /api/review/session | 读取唯一未结束会话及最近成功位置，不因此抢占写权 |
| POST /api/review/sessions | request_id + 本轮设置；有未结束会话时拒绝另开并返回继续入口 |
| POST /api/review/sessions/:id/lease | 显式继续或过期后接管；未过期他窗租约不静默夺取 |
| POST /api/review/sessions/:id/heartbeat | token + version + 前台增量，持久时间与续租 |
| POST /api/review/sessions/:id/next | request_id + version，按本轮剩余额度发卡 |
| POST /api/review/cards/:id/reveal | 返回答案；初次题面响应不携带答案字段 |
| POST /api/review/cards/:id/feedback | result + version，揭晓后反馈；返回已接受记录及最新状态 |
| POST /api/review/cards/:id/skip | 放弃当前卡，不反馈、不重排同会话重复 |
| POST /api/review/sessions/:id/state | pause/resume/end + version；resume 需持有租约 |

预算结束后的只读揭晓不需要活跃写租约、不改变卡状态/时间/调度，但仍校验库 generation 与卡有效性。同窗口所有会话写请求走串行队列，使用最后确认的版本，避免心跳与反馈相互覆盖；心跳冲突重读状态，不能盲目重复累计增量。

这不是防作弊系统，用户仍可在表达库自行查答案；接口分题面与揭晓是防止意外泄漏答案，不能宣传为考试安全边界。

## 6. 与现有编辑、导入和恢复的集成

任意 reveal/feedback/next 前检查 current generation、池状态、实体生命周期和版本。编辑表达/语境/来源、调整语境归属、暂停池、改 P3、归档、删除会使有关未提交卡失效；用户输入保留，已发卡额不退，不伪造反馈。历史 ReviewRecord 保留原所属表达和题目快照，即使当前 Context 已改归属也不能重写历史。

两种 Excel、手动保存、改优先级都不创建 active review_entry；原有记录迁移后默认未加入。现有 Why Saved、Seen、Used、来源统计和行键算法不变。复习反馈不生成 Context，不增加 Seen/Used，不调用外部 AI。

升级前先做一致性 SQLite 快照，再事务迁移。不能在不含新表的旧 schema 2 导出里悄悄漏掉复习数据：RV-A 同时升级数据库和备份为 3。新版导出包含全部四个复习表（含发卡但未反馈记录）、池和会话设置；不包含租约。

当前兼容合同：schema 3 程序接受有效 schema 2 JSON，完成旧字段校验后显式转换为 schema 3（复习四表为空、所有收藏未加入），预览明确警告“恢复旧备份会替换当前库并清除当前复习进度”；用户确认后才替换。schema 3 JSON 按全量校验恢复：检查唯一 ID/引用/阶段范围/参数版本、活跃池容量、唯一未结束会话、每会话表达唯一、issued_count 与卡片事实、首次引入与日期事实、answered 卡与唯一反馈一致；历史快照允许与已改归属的当前 Context 不同，不当成悬空引用。其他版本拒绝。旧 schema 2 程序不能导入 3，禁止简单调低版本号。快照仅保存出题/历史必需字段，不复制整份导入元数据或全部语境；仍须验证长时历史增长对当前 50 MiB 恢复限制的影响，超限不得静默丢弃历史或生成无法恢复的导出。

恢复前依然自动生成当前完整 schema 3 快照，快照成功后才可确认。恢复失败原库不变；成功更新 generation。未结束会话统一恢复为 paused、清除租约；当前卡可读取快照，但继续/反馈前重验引用和版本。ended 会话仍 ended。对 active→paused 的运行态归一化不改题目、反馈或已累计时长。schema 2 旧库中的两种导入元数据和手动记录逐字段保留。

## 7. 文案与可用性

优先用“近期想练”“本轮最多”“暂停练习”“今天先到这里”。可以展示已加入的 12/20 个和本轮 4/10 张，不把它们改写成任务清单。无候选显示“这轮没有可练内容，可以去读点新的”，允许结束。

池满、没有新引入名额、材料待补、无资格题型都使用具体原因；不提示“落后”“欠了”“必须补完”。加入候选必须能看清 term 与义项并分页，不对整本书默认全选。暂停不丢收藏。

键盘可操作加入、揭晓、三种反馈、跳过、暂停和结束；未揭晓答案不被 VoiceOver 读出。实施时记录 Mac Safari/Chrome 版本、200% 缩放和焦点表现；设计文档不算已通过可用性验收。

## 8. RV-A 实施细节（2026-10-17）

- `lib/review-storage.ts` 建表并在业务最外层事务提交前执行资格暂停和卡片失效校验，编辑与自动暂停不会出现半提交；Source 归档保留资格，但来源版本变化会使未反馈旧卡失效。
- `lib/review.ts` 负责池、选题、租约、计时和反馈，时钟从 Store 注入。首次出题日期按 Mac 服务端时区记录；SQLite 写事务与唯一索引共同约束容量、会话和发卡。
- `review_leases` 是运行态第五张支撑表，含 process_id；进程标识变化或租约过期时清理，对应 running 会话安全暂停。四张业务复习表纳入 JSON，租约不导出。
- 会话继续由 lease 接口显式获取/更新租约并恢复 running；state 的 resume 仅允许已有有效租约的 running 持有者续用。暂停会话如要结束，先点击继续获取写权，再结束。
- 卡片快照只保存认义所需材料、义项、语境释义、语言标签、来源/位置和可选 simpleParaphrase；Farm K 列仅在揭晓后作为“学习改写（非原文）”显示。Writing 失败/纠正记录无明确正确改句时不作为学习句，自主使用句可用。
- 恢复 running 会话时转 paused，并提升 session version；已存题目、反馈和有效时长不变，旧页面同时受 generation 保护。已暂停/已结束会话保持其状态。
- 没有加入后台计时器、AI 调用或导入自动入池逻辑。浏览器事件/心跳无法证明真实物理锁屏和休眠的所有行为，待验收边界见 13。
