# 书籍原句填空开发与验收

第二版在现有阅读来源的“翻本书闪卡”入口新增“原句填空”。默认仍是普通闪卡。两种练习共用章节、等级、张数上限、单卡导航和答案区。填空是一轮随手练习，核对只在当前页面生效，刷新后重新开始。

## 实现顺序

1. 出题规则。复用已有高亮定位。优先使用记录中的实际词形及出现序号，缺少实际词形时，只认能精确定位的完整表达。只挖一个位置，保留原文大小写、空格和标点。原句缺失、标为待补充、词形找不到、出现多处、挖空会留下实际词形或词条原形，都使用普通闪卡。待核对原句和没有核对状态的旧资料也可按同样的文字规则出题，待核对状态在题面和答案都显示。同义项在所选范围内优先使用能挖空的语境，再优先选已核对、较新的语境。本轮先选填空题，剩余名额从普通闪卡补齐。
2. 练习界面。题面显示挖空原句和输入框。可输入后核对，也可直接揭晓或跳过。核对时忽略大小写、首尾与连续空白、直弯撇号差异。揭晓后恢复带高亮的原句，显示原文答案、表达原形、释义和出处。原文用词不同的答案允许自行判断是否合理。换卡清空输入和核对结果，保留原有轮次操作。
3. 接口与回归。沿用书籍闪卡已鉴权且禁止缓存的 GET，用 `mode=cloze` 请求填空，省略则沿用普通闪卡。答案随已登录用户的本轮卡片载入，揭晓前不渲染到题面。整轮操作只读，无数据库迁移，不写学习库或 Review 反馈。验收覆盖真实词形、短语、重复答案和词根原形泄漏、章节与等级、普通闪卡回退、手机交互和数据一致性。

## 验收结果

- 121 项单元与 API 测试通过，覆盖大小写和撇号归一、屈折词形、词边界、重复和原形泄漏、无效模式、同义项去重、语境回退及备份一致性。
- 生产构建的 31 项 Chrome 端到端测试与 2 项独立云模式认证测试通过。本地开发服务的两次全量运行分别遇到一次导入 API 返回 HTML、一次历史回退焦点超时，两条用例均在生产构建中通过。
- 393px 和 320px 测试覆盖题面隐藏答案、回车核对、不同用词提示、直接揭晓、清空输入、普通闪卡回退及无横向溢出。实际 iPhone Safari 待验。
- 在内存库导入《Counselling for Toads》的 16 章、628 条语境，第 8 章本轮生成 10 道填空，逐条核对均可恢复原句，待核对状态保留，练习前后全量备份一致。
- TypeScript、格式、网站指南和 Markdown 一致性检查通过。当前版本待线上发布。
