# 邮箱登录与上云准备：实施设计与验收

版本：0.2；日期：2026-10-17。基线：PRD v0.7、schema 3、RV-A Recognition。用户确认使用邮箱＋密码；不使用 GitHub 登录，不开放注册。本轮先交付可在本地验证的代码、运维工具和部署文件；实际云资源开通、凭据配置、邮件送达及真实设备上线另行验收。

## 1. 技术决策与边界

保留单实例 Next.js/Node 24 与 SQLite；以 Supabase Auth 的官方 SDK 管理邮箱密码、凭证、刷新与找回密码。认证服务只管理身份；书籍、原句、草稿、复习及备份仍由本应用 SQLite 保存，不上传 Supabase 数据库。应用不保存或自行散列用户密码，不使用 service_role 密钥。

身份须同时匹配服务端配置的 Supabase user UUID 和规范化邮箱，并且邮箱已验证。使用稳定 ID 避免邮箱改名或账号删除重建误授权。所有业务 API（仅无敏感信息健康接口例外）在打开学习库前验证身份；页面入口也校验，不能只隐藏导航。页面代理不匹配 /api/，避免 Next 默认 10 MB 代理缓冲截断原有 50 MB 恢复请求；API 自己独立鉴权及流式限额。登录跳转按配置的正式 origin，避免反向代理内部 URL 混入 Location。其他账号 403，缺失/失效会话 401，认证服务故障 503，不退回匿名访问。注册能力由提供方后台关闭，应用无注册 API。

模式：默认 `local` 保持现有仅回环访问；`cloud` 强制配置正式 HTTPS origin、认证项目和所有者。开发测试可在非 production 环境以 `cloud` 模式使用回环 HTTP origin/认证模拟服务；production 不允许此例外，无测试账号或生产旁路。未知模式或缺配置直接拒绝服务，绝不回落 local。

使用 `@supabase/ssr` 的服务器 Cookie 适配及官方客户端：HttpOnly、SameSite=Lax、生产 Secure、host-only、Path=/，令牌不入 localStorage/JSON/日志。每次访问以 `getUser()` 远程校验，不把解码 JWT 或 `getSession()` 当成授权。按 SDK 规则刷新，响应携带 Cookie 更新且 no-store。退出撤销会话并清理 Cookie。密码重置由提供方发邮件，恢复 token_hash 验证后方可改密码；改完结束会话并要求重新登录。找回请求统一返回，提供方发送错误仅记录固定错误代码，不泄漏账号是否存在；不提供任意 redirect URL。

参考：[Supabase 密码登录](https://supabase.com/docs/guides/auth/passwords)、[服务端高级说明](https://supabase.com/docs/guides/auth/server-side/advanced-guide)、[Next.js 身份认证](https://nextjs.org/docs/app/guides/authentication)。仅 SDK/官方协议管理密码和令牌，不发明认证算法。

## 2. 请求、部署和数据保护

- cloud 按明确配置的正式 origin 校验 Host 和写入 Origin；忽略外部 X-Forwarded-Host/Proto。受控反向代理必须保留正确 Host，公网只开放代理，应用端口不发布。
- 本地模式继续回环 Host/Origin 校验。认证写请求同样验证 Origin、JSON 和小体积上限；不依赖客户端禁用按钮。业务 generation/版本/复习租约继续保留。
- 维护开关存 `workspace_meta`，不纳入业务 JSON；设置开关与业务写入通过 SQLite 写事务互斥。所有业务写事务检查维护状态；读取/一致性导出仍允许。GET 复习在维护时只读，不推进租约或失效状态。允许环境变量只读作为额外运维开关。
- 迁移工具以只读 SQLite 连接逐表生成稳定 ID、字段摘要、计数和引用检查报告；含四原业务表、四复习表及 generation，不比较运行租约。校验不初始化 Store，避免后台备份进程清理前台复习租约。迁移前停写，迁移后核对，不能重新导入 Excel 代替全库迁移。
- 一致性 SQLite 自动备份使用 SQLite Backup API，不生拷运行中的主文件；写入临时路径，完整性/外键检查、权限收紧和 fsync 后原子发布。故障保留原备份，不公布半文件。备份包含敏感原文和运行态表，恢复启动时租约由进程标识作废。
- 保留最近 7 份日备份、4 份周备份；使用 restic 加密到独立故障域存储。执行异地备份成功后才清理本地过期备份；退出非零及错误提示可接运维告警。不配置异地目标不得宣称异地备份成功。
- Docker Compose：单应用、Caddy HTTPS、持久数据目录、独立备份任务容器；Node 24、非 root 应用、健康检查、发布前备份。生产时区明确 Asia/Shanghai，复习日配额不随服务器默认 UTC 意外变化。更新应用不替换数据卷。
- 手机/iPad 首期查阅；复杂录入/导入继续以 Mac 验收为准。切回前台刷新可见数据，但有未保存输入时不覆盖输入。Review 继续采用原暂停和显式继续规则。
