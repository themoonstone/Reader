# 手机布局修复与验收

日期：2026-10-18。触发：用户在 iPhone 16 成功登录 phrasebud.com，截图显示固定 72px 侧栏中邮箱逐字换行、退出按钮竖排，主内容被侧栏压窄。真实手机登录由用户确认，不等于完整移动端功能验收。

## 修复合同

- 850px 及以下窗口使用顶部导航布局，释放主内容完整宽度；保留四个主要导航、设置、账户与退出能力。
- 账户独占一行，长邮箱单行省略并提供完整 title；退出按钮不换行，触控区域至少 44px。
- 桌面窗口保留原侧栏；小屏内容、工具栏、来源类型筛选和对话框应不产生页面横向溢出。
- 手机文本输入字号至少 16px，减少 iOS 聚焦自动放大；不关闭用户缩放。
- 不改认证、数据库、导入或复习逻辑；本次是响应式布局修复，不宣称 C2 手机完整录入/导入交付。

## 验收与部署顺序

1. 使用合成认证与临时库验证登录后工作空间，模拟长邮箱；检查 320、393、430、768 和 1280px 布局、导航和退出。393px 对应用户设备的目标 CSS 视口。
2. 检查真实工作空间而非仅登录页；保留截图并视觉复核。覆盖一个窄屏来源/采集对话框和桌面原有认证流程。
3. 必要回归通过后，服务器以新标签构建 amd64 镜像。替换前在私有目录保留一致性数据库快照及原镜像；只更新 app，保留数据卷、代理和证书卷。
4. 校验新镜像、健康与公网登录保护、部署前后业务摘要；用户刷新 iPhone 验证真实 Safari。真实设备结果另记，不用浏览器模拟冒充。
