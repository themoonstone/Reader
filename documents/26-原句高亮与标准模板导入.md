# 原句高亮与标准模板导入

日期：2026-10-21。用户要求：学习目标在原句中加粗高亮；不符合格式的 Excel 提示并拦截。先约定、再实现和验收，不操作现有学习内容。

## 约定

1. 详情原句优先按人工填写的实际词形定位；标准模板按出现序号精确定位（默认第一次）。没有实际词形的旧数据按完整词/短语、忽略大小写匹配，不匹配单词内部，不猜测变形或不连续语块。不匹配时保持原文，不伪造高亮。写作改进句单独匹配目标词条，不把旧句词形强加到新句。只改变展示，不改变 Seen/Used、复习和原文。
2. 新增 PhraseBud v1 标准模板读取器，与原有两个适配器并存；仅严格 P1 入库，P2/P3 验证后排除，等级为空明确拦截，不自动评级。使用上一轮生成模板的 15 个列名、语料填写页；填写说明和填写示例不会导入。
3. 标准模板一文件一本书；列可以重排，但不能缺失、重复或含未知列；必填词条、中文语境义、书名、位置（章节/页码至少一项）、状态、等级。原文缺失仅可标待补充；有原文须填写可精确匹配的实际词形，序号须存在。核对备注、例句/译文/来源、搭配分别存储，不把生成例句当原文。待核对/待补充明确显示并预览警告，不视为已核实；仍不自动加入复习池。
4. 服务端校验文件、表头、逐行字段、公式、混合模板和额外数据页，失败不签发导入预览，数据库不写入。客户端显示工作表/行号/列名/修正提示，清除之前预览，不能继续导入。仅已知说明和汇总页允许跳过；保留实际两本历史文件兼容。
5. 签名预览、差异选择、快照、事务和备份恢复保持既有规则；标准模板的中文语境义单独使用，旧模板英文语境义不变。显式修订可更新标准模板高亮实际词形和出现序号，默认保留旧值。扩展 schema 3 JSON 可选字段；旧备份仍可读，旧版本程序不承诺读取新模板的元数据。

## 验收

高亮验证边界、变形、大小写、多个出现序号、标点、跨行、HTML 文字安全；标准模板验证空白模板、错列/错值/公式/混合/额外页、精确位置、P1 筛选、修订去重、备份恢复、缺失原文和中文/例句不串栏。全量领域及浏览器回归、桌面/手机截图、生产构建和隔离鉴权通过后再发布，冻结备份并核对业务数据不变。

## 使用边界

只有受支持的三种格式可导入，不能把任意新书的自定义表头当成标准模板。之前的 Kill Alex Cross 自定义表需要整理进标准模板后上传。字段/位置错误整份拒绝，但待核对/待补充是允许保存的明确状态；不能声称自动验真。

标准模板在整理阶段可以暂不定优先级，但网站导入前必须补上 P1/P2/P3；仅 P1 入库。原文缺失允许留空，但须待补充状态和原因；有原文时实际词形和序号必须精确存在。完整词匹配不猜测时态、代词或不连续短语；旧数据无法定位时保持原文，可在编辑语境中手工补实际词形。

本轮 schema 仍为 3，增加可选导入元数据；新程序兼容旧 JSON。若已有新标准模板内容写入，不可直接回退旧程序并假定旧程序支持新元数据；先保留最新全量备份，再评估兼容修复。发布冻结期的自动回退仅适用于没有新业务写入的部署失败，不能以旧快照覆盖后来数据。
