## 3. 本次修正的易混淆点

1. PRD 的 MUST 表示交付要求，不表示现有代码已经完成；当前仅有手动闭环、专用 P1 导入和帮助指南等子集，未宣称完整 R0 交付。
2. 原 Mac 本地决策保留为历史基线，C 阶段增加设备、身份与部署要求；C1 上线条件不依赖先完成 AI/Review，但不取消这些原需求。
3. 来源归档已实现；表达归档操作、正式表达/Context 编辑删除未实现；“包含归档表达”筛选只能列为部分实现。
4. 响应式 CSS 不等于手机/iPad 已能访问，浏览器页面不等于 PWA；当前仅回环监听、没有账号和云端服务。
5. Excel 严格 P1 只支持指定模板，不能替代全库迁移、备份或 JSON 恢复；不推断用户库的当前条数。
6. 云端使用同一后端数据库，离线双向同步另行评审；迁移后只保留一个日常写入库，回退必须考虑云端新增数据和 schema 兼容性。
7. 云端自动备份、恢复时间、监控与费用均是待实施目标；CA-01–CA-10 全部未执行，不把方案当成已部署证据。
8. 区分 Excel 导入接口的 8 MB JSON 限制、普通接口的 128 KB 限制和未来全库恢复的 50 MB 建议，后续恢复需单独设计。
