# Our Little Farm 导入说明与验收

日期：2026-10-17。需求：PRD v0.5 / FR-12 增量。代码基线：在 `cd63cbf` 后新增第二模板；不修改原 Excel，不自动导入用户正式库。

## 1. 操作步骤

1. 刷新网页，点击顶部“导入 Excel”，选择 `resources/Our_Little_Farm_Vocabulary-4.xlsx`。
2. 检查识别结果为“Our Little Farm 章节词汇表”。明细共 373 行，P1 50、P2 192、P3 131；跳过“P1 优先掌握”汇总。
3. 来源标题建议为 Our Little Farm；唯一同名有效 Reading 来源会自动选中，否则新建或人工选择。确认确实属于这本书，避免选到原书。新建状态为“阅读中”，复用不改原状态。
4. 展开分组核对原句、释义、改写和理由。已有同词默认跳过；人工选择新建、按行拆分、追加已有 P1 或跳过，不能无条件按拼写合并。
5. 勾选确认并提交。空库全选新建时得到 50 个表达、50 条语境；实际数量受已有候选和用户选择影响。
6. 点击“查看本书的表达”，按 P1 筛选并打开详情；展开 Excel 导入信息查看原表来源、页码、词性、学习理由与学习改写。

仍只导入 P1，P2/P3 只参与统计和等级冲突检查；无自动重新评级、AI 调用或通用列映射。上传预览不写业务库，必须明确确认。

## 2. 两种模板与字段

| 项目 | Bringing Up Bébé | Our Little Farm |
|---|---|---|
| profile | bebe-strict-v1 | little-farm-v1 |
| 表头/首条数据 | 第 1/2 行 | 第 5/6 行 |
| 明细范围 | 原英语列名识别 | Our Little Farm 标题 + Preface/Chapter N + 中文列 |
| 汇总 | 跳过不符合明细列的统计/汇总 | 显式排除 P1 优先掌握，只读前言/章节 |
| 表达/义项 | Circled item / Dictionary core Chinese | 词汇 / 表达 / 中文释义 |
| Context.meaning | 原表英文语境释义 | F 列本书语境义（英文） |
| 原句 | Sentence / context | H 列原文片段 |
| 位置 | 原有 Page/原文页码映射不变 | B 列拆出标记方式与页码，同时保存完整原字符串 |
| 学习辅助 | 原复习目标/搭配 | K 列简单英文释义/学习改写单独保存，不作原句或通用同义替换 |
| 类型 | 原 Type 枚举映射不变 | pattern → sentence_pattern，idiom/saying/sentence/wordplay → chunk；其余单词/多词按 word/phrase 映射，原词性完整保留 |
| 计数 | 每条真实明细一次 | 每行一次，4,10 等合并页码不拆成两次 Seen |

章节名、行号、原词条、原句及页码参与行键；profile 是去重命名空间的一部分，旧书行键构造不变。文件改名不影响相同来源的去重；重排、改词或改原句不保证智能识别为同一事件。删除的已导入记录不会因重传而自动恢复，应使用回收站。

## 3. 实现与兼容性

`lib/little-farm-import.ts` 为独立适配器，在现有工作簿安全检查后识别。原 bebe 解析分支保留表头、类型、字段和行键规则；两种格式共用签名预览、分组确认、候选校验、低等级保护、去重和事务入库。

只接受受支持的前言/章节结构。缺列、重复表头、公式、无效等级、缺必填释义、混合两种模板或只有汇总表均拒绝。位置文本无法解析时保留原值并留空 page，不猜页码。

ImportPreview 新增 profile、格式名称和建议书名。客户端按识别结果重置书名、来源与确认状态，避免先上传一本书后继续使用上一本书的默认来源。既有同词仍默认跳过。

importMetadata 增加可选的 sourceMark、rawSourceLocation、simpleParaphrase，并允许 little-farm-v1。旧字段不改名、不添加默认值覆写旧数据；原 JSON 备份仍可由新版读取。业务表结构和 schema_version=2 不变，新格式元数据随当前 JSON 导出/恢复及语境编辑保留。旧程序不认识新 profile，恢复含新书的备份前应更新到支持该格式的版本。

不改 Host/Origin/generation 校验、恢复逻辑、草稿保存、计数定义或旧书分组语义。恢复与维护、原书和新书的回归分别执行。
