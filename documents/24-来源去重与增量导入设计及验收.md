# 来源去重与增量导入设计及验收

日期：2026-10-18。根据用户确认：默认复用同一来源、对比后增量合并，不整库覆盖，不丢弃未出现在新文件中的旧记录。实现前约定如下，实际验收和部署结果见文末。

## 来源

同类型、名称经 NFKC/空白/英文大小写规范化后相同则提示。新增与改名由服务端复核；允许用户明确新建独立同名来源。作者、日期可作为提示，不假设同名就是同一作品。来源 ID 的重试保持幂等。

Library 提供合并入口，用户选择保留的来源并查看预览，确认后将原来源的全部语境与草稿（包括已保存、忽略、回收站）归入目标，原来源归档。保留目标元数据及所有义项 UUID、复习池/记录/历史快照，不按词形自动合并独立义项。同一义项下，完全相同的语境内容才折叠为一个有效语境，重复项移至回收站保留可恢复记录；同词不同义项或不同语境不折叠。Seen/Used 按有效语境重新计算。

合并必须先生成全量 JSON 快照，再在单事务中更新引用、版本、事件指纹和来源归档。签名预览绑定当前来源/表达/语境/草稿状态，过期或任何关联编辑后拒绝提交，防止遗漏刚新增内容；快照失败则不修改。

## Excel

既有两种模板、仅严格 P1、中文义项与英文语境分离规则保持。增加确认前差异预览：新增、完全重复、内容变更、含糊匹配/已删除等保护项。先精确导入键，再同模板同词的原句/章节/位置识别重排；原句或位置修改可按唯一原表位置提出变更候选，但须明确选择，不自动认定同一次接触。重排时旧句已出现在新文件其他行，则不按旧行号误更新。多候选不自动覆盖。

默认新增缺失内容、跳过重复及保护项、保留冲突旧值；用户逐项选择使用新语境值，或批量对已确认候选使用新值。没有出现在新文件中的旧数据保留。更新仅涉及语境原句/位置、导入语境解释及最新导入元数据；保留个人笔记、事件、优先级、表达义项释义、替换表达和复习进度。要改表达义项仍通过原维护入口，避免一个导入行覆盖同义项的所有使用。

新增行仍须明确分组/选择义项；相同词形但释义不同不强行合并；旧 P2/P3 不因导入升级。重复检测忽略文件名和行号漂移，优先保留用户已编辑版本；已归档/删除数据不自动复活。更新前快照、签名差异凭据、generation/状态校验与全批事务回滚不可绕过。旧调用未提供差异凭据只允许安全新增/跳过，不允许更新。

## 验收

验证来源规范化、明确保留同名、合并引用/回收站/复习保留、内容不同不折叠、快照失败/并发/过期/事务回滚；验证文件重传/改名/重排、新增/变更、手动笔记/优先级保护、不同义项、两模板共存、实际工作簿、恢复往返及 UI 确认流程。生产部署不自动合并用户来源或重导表格，由用户在新界面明确确认。

实现和自动化验收完成，2026-10-18 已部署正式网站。部署没有自动合并用户来源或重新导入用户表格。

### 用户操作与已知边界

1. 刷新 [正式网站](https://phrasebud.com)，在 Library 点击“合并来源”。先选原来源，再选保留来源，预览后勾选确认并提交。原来源归档，目标保留其名称、作者等资料；可用“查看归档来源”查看原来源。
2. 同名新增/改名时，选择复用已有来源，或明确保留独立同名来源。同类型名称防重不是所有作品的唯一身份判定；不同作者的同名书仍可独立保存。
3. 上传同一本书的新版表格，选择已有来源、核对 P1 分组，点击“对比本次导入”。重复项跳过；新增项按所选分组添加；变更默认保留旧值，仅对确认的修订选择新值，再勾选最终确认并导入。
4. 需要将变更另存为独立义项时，分组选择新建/拆分后重新对比，再选择新增；多候选项不自动覆盖。来源/分组选择变化会清除旧预览。

不承诺识别任意改写后的句子属于同一次阅读；无法可靠匹配时要求人工决策。已归档/删除内容不自动复活，独立义项不按词形合并。合并会更新材料版本，当前显示中的 Review 卡可能按既有规则失效，但过往自评历史保留。预览有效期 30 分钟，服务重启或学习材料变化也会要求重新预览；单纯 Review 进度变化不阻止提交。全库快照与状态摘要适合当前个人数据规模，尚未完成万级表达/五万语境性能验收。
