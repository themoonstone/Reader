# 书籍闪卡与轻量复习

日期：2026-11-14。状态：F1–F4 已完成实现和验收，已发布至 `phrasebud.com`。真实 iPhone Safari 待验。

第二版的原句填空见 [31](31-书籍原句填空开发与验收.md)。

- F1：阅读来源页添加“翻本书闪卡”。先选章节、表达等级（P1/P2/P3 或全部）及最多 5/10/20 张（默认 10）。候选只取本书有效语境和有效表达，按表达 ID 去重；不同义项不合并。代表语境优先有原句，再优先已核对的语境，最后按最近记录确定；章节缺失可以单独筛选。等级以表达当前收藏等级为准，与来源列表一致。
- F2：单卡显示表达与原句，复用精确词形/出现序号高亮；没有指定词形时沿用完整词或短语匹配。揭晓后显示释义、出处、原文状态，可展开例句和备注。无原句可看释义，但不造句；待核对原文明确标记。支持上一张、下一张、跳过、结束；结束可重选范围，返回原书。
- F3：两种入口共享卡片布局。随手翻卡仅通过已鉴权的 GET 读取、状态仅在当前页面内存；无复习写入、无后台加入、刷新不恢复轮次。Review 沿用既有池、资格、配额、揭晓门禁、反馈和多窗口保护。历史快照格式不变，Review 旧题仅按原形匹配高亮。
- F4：验收选章不串书、同义项不重复、P3 可翻、缺原句/空范围、揭晓前界面无答案、手机底部按钮可达，以及翻卡前后学习库/Review 完整一致；回归 Review、备份、鉴权与生产构建。填空、配对、翻译和 Anki 接入不在本轮。

## 验收记录

- F1：新增已鉴权、禁止缓存的 `GET /api/sources/:id/flashcards`。仅返回本书的章节清单或本轮最多 20 张卡；超出本轮上限时无放回抽取。归档表达和非活动语境不参与。测试覆盖同词不同义、跨书语境排除、未标章节、空结果、非法参数和写请求拒绝。
- F2：393px Chrome 验证章节及 P3 筛选、实际词形高亮、无原句回退、空格及按钮揭晓、上一张/下一张、跳过、结束和返回原书；截图检查无横向溢出。揭晓前不渲染答案，翻页后重置揭晓状态。随手翻卡的答案随批次读取，仅在前端隐藏；Review 保持服务端揭晓门禁。
- F3：浏览器和内存库分别对比翻卡前后的完整 JSON 备份，除导出时间外完全相同。现有 Review 揭晓、反馈、跳过、暂停恢复和多窗口租约回归通过；未改数据库 schema 或快照格式。
- F4：在内存库导入《Counselling for Toads》真实全量表（628 条语境），识别 16 章，第 8 章抽取 10 张，全部属于所选章节、义项无重复，抽卡前后业务数据一致。120 项单元/API、31 项 Chrome 端到端回归、TypeScript、生产构建、格式与指南一致性检查通过。测试使用隔离学习库。
