# 书籍英中配对开发与验收

第三版在书籍闪卡入口加入“英中配对”，用于短时热身。范围沿用本书、章节与表达当前收藏等级。默认每轮 4 对，可选 4、5 或 6 对。整轮使用页面内存，配对结果与失误不进入学习库或 Review。

## 实现顺序

1. 组题。使用已收藏义项的英文表达和中文释义，只取所选范围内的有效表达。没有中文释义的义项跳过。规范化大小写、全半角和标点后，同形英文以及共享中文释义片段的义项不能同轮出现。规则识别文字重复与明显包含关系，无法判断任意近义词。冲突较多时尝试多种抽取顺序，目标数量凑不齐时可缩至 4 对，低于 4 对提示重试或扩大范围。两列打乱，避免正确选项整列按行对齐。
2. 交互。手机与电脑都用两列按钮，点英文或中文均可开始，下一次点另一列完成核对。配错可以重新选择，配对成功的选项保留在原位并标记完成。支持键盘，显示本轮进度，可随时结束或返回书籍，完成后可以重选范围。
3. 验证。沿用鉴权且禁止缓存的只读接口。验证筛选、冲突过滤、不足提示、鼠标和键盘操作、窄屏布局与练习前后备份一致。回归普通闪卡、原句填空、Review、导入与备份。

`GET /api/sources/:id/flashcards?mode=match&limit=4` 复用现有入口。配对模式的 `limit` 仅接受 4、5 或 6，可附带 `chapter` 和 `priority`。两列选项按义项 ID 关联，核对在已登录用户的客户端完成。旧模式继续使用原响应结构与张数限制。无需数据库迁移。

## 验收结果

- 123 项单元和 API 测试通过。配对接口覆盖 4/5/6 对、同形和释义重叠过滤、章节与等级、归档项排除、数量不足、顺序打乱、禁止缓存和备份一致性。
- 320px Chrome 连续完成三轮独立浏览器验收，包含超长表达换行、键盘和双向点选、错误重试、结束与重开，以及底部操作不遮挡选项。练习前后全量备份一致。
- 最终生产构建的 32 项 Chrome 端到端测试全部通过，包括旧闪卡、原句填空、Review、导入与备份。TypeScript、格式、指南一致性与 Git diff 检查通过。
- 《Counselling for Toads》全量 628 条语境在内存库试验。Chapter 8 的 P3 连续抽 20 轮，每轮 6 对，范围正确且无命中既定冲突规则的选项，练习前后备份一致。
- 2 项隔离云模式认证测试重跑通过，验证未登录访问配对 API 返回 401。首次运行的密码恢复用例在页面导航过程中有一次浏览器执行上下文中断，重跑通过。
- 待真实 iPhone Safari 验收和线上发布。
