# ReadWords 使用指南

更新日期：2026-10-18。内容以网站当前实现为准。

从第一次打开，到找回自己的表达。

你可以把这里当作一本能搜索的英语摘录本：先记录书、播客或自己的写作，再留下值得学习的表达和当时的那句话。当前版本可以采集、整理、导入、查阅，以及手动选择少量表达做认义复习。

在线阅读：[网站使用指南](http://127.0.0.1:3000/guide)。也可从页面右上角“使用指南”进入。

## 1. 你现在应该从哪里开始？

1. 已经导入 Bringing Up Bébé：点左侧 Library，在书籍卡片上点击书名，进入本书表达列表。不要为了查看内容再次上传表格。
2. 还没导入：点页面右上角“导入 Excel”，按下一节操作。这是你目前最快的开始方式。
3. 想随手记一个新表达：点右上角“＋ 记录表达”。先保存到 Inbox，之后再整理。
4. 想找一个已经保存的表达：点左侧 Search，输入英语、中文释义、原句片段或书名。

导入结束后没有立即看到表达也不用重传：先到 Library 找到本书，或到 Search 搜索。

## 2. 把这份 Excel 的 P1 导入进来

1. 点击右上角“导入 Excel”，再点击“上传 Excel 文件”选择文件。
2. 文件在 Reader/resources 文件夹。Mac 文件选择窗口里按 ⌘⇧G，粘贴 /Users/Admin/Src/themoonstone/Reader/resources/，回车后选择 bringing_up_bebe_vocabulary_strict_P1_P2_P3.xlsx。
3. 等待预览。应看到章节明细 1,098 行，其中 P1 120、P2 514、P3 464。本次功能只导入严格版 P1，P2/P3 和汇总表不会导入。
4. 在“导入到 Reading 来源”选择已有的 Bringing Up Bébé；如果还没有，就选择“新建书籍来源”，保留默认书名。
5. 展开词条检查原句与义项。已有同词会默认跳过；可勾“仅查看已有同词 / 等级冲突”快速找到需要决定的组。具体怎么选择见下一节。
6. 滚动到页面底部，勾选“我已确认所选分组的义项与严格 P1 等级…”，再点“确认导入 N 条 P1”。只上传并预览，还不算保存进表达库。
7. 看到“导入完成”后，点“查看本书的表达”。页面会按 P1 筛选；点击任意表达卡片查看原句、释义和导入信息。

空库按默认分组导入，会得到 112 个表达、120 条语境：同一表达可以保留多条原句。这个口径与表里 101 个去重复习目标不同。跳过部分分组或选择拆分时，数量也会不同，以页面为准。

当前支持这份严格分级表和 Our Little Farm 章节表两种格式，不是任意 Excel 模板。文件限制 5 MB，预览 30 分钟内有效；服务重启或预览过期，需要重新上传。

## 导入 Our Little Farm 的 P1

1. 点顶部“导入 Excel”，选择 resources/Our_Little_Farm_Vocabulary-4.xlsx。无需修改原表格式。
2. 检查“已识别：Our Little Farm 章节词汇表”。应显示 373 条章节明细，P1 50、P2 192、P3 131；“P1 优先掌握”汇总表被跳过。
3. 来源会建议 Our Little Farm；若已有唯一同名且未归档的 Reading 来源会自动选中复用。确认当前选择确实属于这本书，不要选 Bringing Up Bébé。
4. 检查分组，已有同词默认跳过。选择是否新建义项、追加已有 P1 或暂不导入，不确定时先跳过，不自动合并两个意思。
5. 勾选确认并点击“确认导入 N 条 P1”；空库全部默认新建时，得到 50 个表达、50 条语境。有已有同词或手动跳过时，以本次选择为准。
6. 点“查看本书的表达”，打开详情并展开 Excel 导入信息，可查看原表词性、来源标记/页码、学习理由及简单英文释义 / 学习改写。

新建的 Our Little Farm 来源默认“阅读中”，不根据已整理的章节推断整本书读完。原文片段来自 H 列，学习改写来自 K 列，两者分别保存，不把改写当作书中原句。中文释义保留在表达义项，英文语境义单独保留；没有自动翻译或重新评级。

原表一行合并多个页码时，仍只算一条记录；例如 4,10 原样保留，不增加两次 Seen。页码未提供就留空。当前仍只导入 P1，不导入 P2/P3，也不开放任意模板映射。

## 3. 导入时，分组到底该怎么选？

第一次导入、库里没有同词时，可以先逐组检查默认的“新建此义项”。同一个拼写不一定是同一个意思，不确定时先跳过。

已有 P2/P3 或已归档的义项不能直接追加；可以先在表达详情“编辑表达”中调整等级，或取消归档，再重新预览导入；仅在确实属于独立义项时新建，不要为了导入随意制造重复。

如果报“已有同名来源”，回到来源下拉框选择复用已有书籍。已归档的来源要先在 Library 勾选“查看归档来源”，点“编辑”并恢复。

| 页面选项 | 什么时候选 | 会发生什么 |
| --- | --- | --- |
| 新建此义项，组内语境合并到一条表达 | 这一组是同一个意思，库里还没有，或与已有表达意思不同 | 新建一个表达，保留本组每条原句 |
| 每行单独保存为独立义项 | 虽然中文写得相同，但你认为这些行的含义不能合并 | 每行各建一个表达 |
| 追加：已有义项 | 库里已有同一表达、同一意思，而且它是 P1 | 增加语境，保留原有表达的释义与等级 |
| 本组暂不导入 | 暂时不确定、不想学，或想稍后再处理 | 这一组不写入；以后可重新上传并只选择这些组 |

## 4. 四个页面分别做什么？

右上角“＋ 记录表达”用于手动采集，“导入 Excel”用于已整理好的表格。左下角“本地工作空间”查看数据位置等说明。右上角“使用指南”会在新标签页打开本指南，原页面的输入会保留。

| 入口 | 用途 | 你可以做的事 |
| --- | --- | --- |
| Library · 来源库 | 管理材料从哪里来 | 建书籍、播客、写作来源；点击来源看其表达；编辑或归档来源 |
| Inbox · 收件箱 | 整理新采集的草稿 | 补来源和释义，选择学习优先级，确认入库，或忽略、恢复草稿 |
| Review · 轻量复习 | 挑选近期想练的表达 | 手动入池后限时限量认义，不自动安排全部收藏 |
| Search · 搜索 | 找已经入库的表达 | 搜索、按来源类型或 P1/P2/P3 筛选，再点卡片看详情 |

## 5. 手动记录一个新表达：跟着做一次

1. 在 Library 点“＋ 新建来源”。例如选择 Reading，标题填写 Slow Down，点“创建来源”。同一本书只需建一次，不需要上传整本 PDF。
2. 点“＋ 记录表达”，选择 Reading。目标表达填写 carve out，原句填写 I carve out some time every morning.，来源选择 Slow Down。
3. 点“加入 Inbox”。系统会打开整理页：这一步保存的是草稿，还没有进正式表达库。
4. 在“当前语境释义”填“专门腾出时间”。确认来源、事件类型和 Why saved；需要的话填章节、页码。
5. 选择 P1（希望主动使用）、P2（认识即可）或 P3（记录即可）。看到“草稿已保存”表示整理进度已落盘。
6. 点“确认入库”。成功后进入表达详情，并能从 Search 找到它。

- 赶时间时，采集可以只填目标表达；正式入库前仍需来源和释义等必填信息。
- 原句和位置可以留空，不会自动补造；缺少原句会限制未来的相关练习。
- “草稿已保存”或“保存草稿 / 重试”只保存整理进度；“确认入库”才会让记录进入正式搜索结果。
- 录入时没建来源也没关系：可以在采集弹窗或整理页点击“新建来源”。

## 6. 阅读、听力、写作该怎么区分？

写作例子：原表达 cost my energy，改进表达 drain my energy，完整改进句 The long commute drains my energy.。目标表达填你想积累的 drain my energy，事件选“获得纠正”；这不会被算作你已经自主使用。

| 来源类型 | 怎么填 | 注意 |
| --- | --- | --- |
| Reading | 书名或文章名，原句；章节、页码选填 | 一本书复用一个来源，不必按章节分别建书 |
| Listening | 播客或视频标题、原句；时间位置可填 03:42 | 只是记录位置；当前不会上传音频、播放或自动提取字幕 |
| Writing | 自己的日记或写作来源，选择表达失败、获得纠正或已自主使用 | 选择获得纠正时，需要不同的原表达和改进表达 |
| Manual | 不知道具体出处的手动记录 | 仍可说明是遇见、想表达但不会，还是已自主使用 |

## 7. Inbox：保存、忽略、重复词怎么处理？

- 整理时会自动保存，留意右上角“等待保存… / 保存中… / 草稿已保存”。离开前最好等到“草稿已保存”。
- 保存失败时不要立刻刷新：当前输入仍在，可点“保存草稿 / 重试”；必要时先点“复制当前输入”留一份。尚未持久化的修改可能在关闭页面后丢失。
- 暂时不想收录，点“忽略”。找回时进入 Inbox，勾选“查看已忽略”，打开记录后点“恢复到 Inbox”。
- 发现相同表达时，系统会列出已有义项：确实是同一个意思就选已有项，意思不同就选“这是另一个义项，单独新建”。追加时保留已有表达的等级。
- 提示“可能是重复接触记录”时先检查原句和位置。如果确实是另一次接触，再勾选确认后保存；不要用重复提交凑 Seen 次数。
- Excel 的批量确认是例外：因为已经整理过，确认后直接入库，不再逐条经过 Inbox。

## 8. 怎么找回并查阅已经保存的内容？

1. 按书查看：Library → 点击书籍卡片的书名 → 浏览该来源的表达列表。
2. 跨来源搜索：Search → 输入英语表达、中文释义、原句片段或来源标题。可以用下拉框筛选 Reading/Listening/Writing/Manual 或 P1/P2/P3。
3. 找不到时先清空关键词，确认来源类型和优先级没有把结果过滤掉；尚在 Inbox 的草稿不在 Search 中。
4. 点击结果卡片打开详情，读原句、语境释义和保存原因。有多条 Context 时，向下滚动查看每一次记录。
5. Excel 导入的详情可以展开“Excel 导入信息”，查看词典中英文释义、音标原记录、复习搭配、等级理由和 Excel 行号。

P1 表示你希望主动掌握，不代表系统会自动安排复习，也不代表已经掌握。需要练习时，到 Review 手动选择少量表达加入复习池。

## 维护已保存的表达和语境

1. 在 Library 的来源下或 Search 中打开表达详情，找到“维护已保存数据”。Library 展示正式内容，Inbox 是尚待确认的草稿；确认入库后才成为正式表达。
2. 点击“编辑表达”，修改表达、义项、类型、P1/P2/P3 或简单替换，再点击“保存修改”。修改表达释义不会覆盖每条语境释义；改名不会自动合并相同拼写。
3. 点击对应记录的“编辑语境 / 归属”，修改原句、语境释义、来源、位置、日期、事件、原因和备注；也可以选择另一条表达/义项作为归属。确认后只移动这一条语境，计数重新计算。
4. 归档表达后，普通搜索隐藏它；在 Search 勾选“包含归档表达”可找到并取消归档。来源归档与表达归档是两回事。
5. 删除单条语境后，可在该表达的“语境回收站”展开并恢复；删除最后一条语境仍保留表达，并显示无上下文。
6. 表达移入回收站时，有效语境一起移入。在左下“本地工作空间”的“表达回收站”恢复；此前已单独删除的语境仍需单独恢复。回收站不永久清空。

修改冲突或保存失败时输入仍保留；先复制输入，再重开最新详情修改，不要强行覆盖。Excel 原始元数据保留，修改后的语境以当前编辑内容为准。来源删除、批量合并/拆分和整批撤销导入尚未提供。

## 9. 页面上的词和数字是什么意思？

| 名称 | 含义 |
| --- | --- |
| Source · 来源 | 一本书、一篇文章、一集播客或一篇自己的写作 |
| Expression · 表达 | 一个词、短语或语块的一个意思；相同拼写可以有不同义项 |
| Context · 语境 | 你记录的一次接触或输出，包含来源、原句等信息 |
| Why saved | 这次为什么保存：没理解、好用、表达失败、写作被纠正等 |
| P1 / P2 / P3 | 希望主动使用 / 认识即可 / 记录即可，不是掌握程度 |
| Seen | 你记录的遇见次数；导入时不会再按原表出现次数额外叠加 |
| Used | 你明确标为“已自主使用”的次数；获得纠正和复习不算 |
| Contexts / Sources | 这条表达的语境记录数 / 不同材料来源数；同一书里多条语境仍是一个来源 |

## 10. 当前能做什么，还不能做什么？

| 功能 | 当前状态 |
| --- | --- |
| 来源管理、手动录入、Inbox、搜索详情 | 可用；来源可以编辑、归档和恢复 |
| 两种 Excel 模板的 P1 导入 | 可用；必须先预览并确认，仅支持相应格式 |
| Review 认义复习 | 可练习；手动入池，默认最多 10 分钟/10 张/3 个首次练习表达。主动回忆和写作回忆尚未实现 |
| AI 整理、拍照 OCR | 尚未上线；目前不会自动解释或识别照片 |
| 已保存表达/Context 的编辑、删除、回收站 | 可用；详情中维护表达和语境，设置中恢复整条表达。暂不能整批撤销导入 |
| JSON 备份恢复 | 可用；设置中下载全库、预览并确认替换；CSV 导出尚未上线 |
| 整本 PDF 上传、阅读器、音频播放、跨设备同步 | 当前不支持；这台 Mac 的本地数据不会自动同步到手机 |

## 10A. 怎样做一点轻量复习？

1. 打开 Review，点击“选择近期想练的表达”。按来源或关键词查找，看清词条和义项后勾选，再点击“加入所选表达”。也可在表达详情直接“加入复习池”。只接受未归档的 P1/P2，需有真实原句或正确改句及语境释义。
2. 活跃池最多 20 个义项；没有整书自动加入。先试 3–5 个即可。暂停或移出只退出练习，不删除收藏和历史；补材料或恢复表达后，仍需手动恢复练习。
3. 默认本轮最多 10 分钟、10 张卡、3 个首次练习表达，可自行调整。全日首次引入最多 5 个，跳过也占名额，重新开一轮不会重置。冷却中的表达不提前出现，无可练内容时提前结束。
4. 点击“开始本轮练习”，先看目标表达和原句，再“揭晓答案”。自行选择“忘了 / 有点难 / 记得”，然后“下一张”；也可直接跳过。反馈只调整下次允许出现的时间，不计算正确率或掌握度，本轮不反复重试同一个表达。
5. 随时“暂停练习”或“今天先到这里”。切后台会暂停；刷新、休眠、断网或服务重启后，以最近成功保存位置继续，不补算离开时间。看到“继续本轮练习”后明确点击。另一窗口仍持有租约时需回到原窗口或等待约 15 秒重试。
6. 到时间后不再保存反馈，当前卡仍可只读揭晓；最后一张卡在未超时前可以反馈一次。结束页分别显示展示数和实际反馈数，不要求完成上限，也没有欠账或补课。

Safari 默认可用 Option+Tab 移动到按钮、空格键激活。本阶段只有认义（Recognition），尚无挖空主动回忆、写作回忆或 AI 判题。复习不会增加 Seen/Used。表达、语境、来源或池状态被编辑时，未反馈的旧卡可能失效，跳到下一张即可；已保存反馈仍保留原题快照。

## 11. 关闭网页后，数据还在吗？

1. 下次需要启动时，在终端进入 /Users/Admin/Src/themoonstone/Reader。
2. 执行 npm run dev，保持这个终端运行，打开 http://127.0.0.1:3000。依赖已经安装时不需要每次重新 npm ci。
3. 要停止时回到终端按 Control+C。关闭浏览器标签页本身不等于停止服务。

已显示保存成功的数据在本机数据库里，关网页、停止服务后仍保留；下次启动可继续使用。默认本地模式无需登录，没有云端副本。配置并部署 cloud 模式后使用唯一所有者邮箱＋密码登录，各设备访问同一服务器；推送 GitHub 本身不会迁移学习数据。

默认数据库在 /Users/Admin/Src/themoonstone/Reader/data/readwords.sqlite。若设置过 READWORDS_DB_PATH，实际位置以该配置为准；切换数据库位置不会自动搬迁原有数据。

点击左下“本地工作空间”，找到“备份与恢复”，点击“下载全库 JSON 备份”。检查浏览器下载文件夹，将文件另存到安全位置；JSON 可能包含私人写作，不要公开。Git 提交只保存代码，不会保存学习库。

恢复前先保存或复制所有窗口中未保存的输入。选择本程序导出的 JSON（上限 50 MB、当前 schema 3，兼容有效 schema 2），检查来源、表达、语境、草稿及复习记录数量；旧 schema 2 不含复习数据，确认替换会清除当前复习进度；预览会先保存当前库的恢复前快照。勾选确认后点击“确认替换整个学习库”，成功后网页会重新加载。恢复是全库替换，不是合并。

预览 10 分钟有效；期间数据发生变化时必须重新预览。恢复后其他旧窗口会被阻止继续写入，先复制输入再刷新；不要反复提交旧页面。

需要撤回恢复时：在设置的“恢复前快照”下载对应快照，再从上方选择该 JSON，检查并确认恢复。快照会保留，不自动清理；它与数据库在同一台 Mac，不能替代异地备份，自动加密备份已有运维脚本，但只有配置异地仓库并启动备份服务才运行，不能假定当前已启用。

首次升级 schema v1 到 v2、v2 到 v3 前会在数据库旁 snapshots/<数据库文件名>/ 目录生成相应 before-schema-v2-*.sqlite / before-schema-v3-*.sqlite 一致性快照；它不是 JSON，不要在网页恢复入口上传。人工应急恢复步骤见项目 documents/09 文档。数据库运行时不要单独移动或删除 sqlite、-wal、-shm 文件。

## 11A. 邮箱登录和云端版本怎样使用？

默认本地地址仍可直接使用。只有运维人员按部署手册开启 cloud 模式、配置真实认证项目和唯一所有者后，才会出现登录页；目前没有已部署的正式云端网址。

在正式私有网址填写你预先创建的邮箱和密码，不提供注册。密码由认证服务管理；学习原文、表达、草稿和复习仍保存在应用服务器数据库。账号配置与部署步骤见 documents/15。

忘记密码时，从登录页进入“忘记密码”，填写邮箱；如果邮箱可用会收到邮件，打开链接后设置 12–128 字符的新密码，成功后重新登录。邮件送达需要正确配置认证项目、恢复邮件模板和 SMTP。

登录失效时先保留或复制未保存输入，通过错误提示的“在新标签页登录”重新登录，再回原页重试，不会为了登录自动清空当前表单。显式退出会离开页面，请先保存当前工作。

云端切回前台时会刷新列表；有未保存输入或打开录入/导入表单时保留输入，保存后再刷新。Review 切后台仍暂停，需要明确继续。手机和 iPad 尚未完成真实设备完整验收。

维护只读时可以查阅和下载 JSON，保存、导入、恢复及复习操作会提示稍后重试；不会假报保存成功。真实邮箱登录、退出重登已在独立环境验证；正式 HTTPS、密码恢复邮件、异地备份和线上设备验收尚未完成。

## 12. 遇到问题时先看这里

| 遇到的情况 | 怎么处理 |
| --- | --- |
| 网页打不开或提示无法连接本机服务 | 确认终端中的 npm run dev 仍在运行；先启动服务，再刷新网页 |
| 没有导入 Excel 或使用指南按钮 | 刷新页面；运行旧 npm start 时，需要停止旧服务并构建新版，或改用 npm run dev |
| 上传后确认按钮不能点击 | 检查是否选中了至少一组、来源标题是否为空，并勾选页面底部的确认框 |
| 导入条数少于 120 | 检查是否有已有同词被默认跳过，或手动跳过了某组；展开相应分组后明确选择 |
| 预览失效或超过 30 分钟 | 重新选择原文件并检查预览；同一来源中已导入的同一明细会跳过，不要为了重试另建一本书 |
| Search 搜不到刚录入的词 | 先检查 Inbox 是否还未确认入库，再清空搜索筛选；也可直接从 Library 的来源卡片查找 |
| 内容已在其他窗口修改 | 先复制当前输入，重新打开最新草稿后再修改；不要反复提交旧页面 |
| 看到本地存储操作失败 | 先保留或复制当前输入，检查磁盘空间和服务状态，再重试；不要删除 data 文件夹 |
| 点 Review 没有练习 | 先在 Review 点击“选择近期想练的表达”，勾选合格的 P1/P2 并加入。池为空、冷却中或首次引入名额已用完时不会硬塞新题 |
