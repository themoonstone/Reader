## 1. 目标与当前边界

目标操作：选择 Excel → 查看工作表清单 → 单选、多选或全选可见数据页 → 检查所选内容 → 复用书籍来源/选择义项 → 对比已有记录 → 勾选现有批量确认 → 原子导入。

典型材料：同一本 Counselling for Toads 的 `Chapter 1–7`、`Chapter 8`、`Chapter 9` 分页整理；每次可只选新章，也可选择全部数据页重新核对。不会要求用户重复删除旧章节，也不会按“本次没选中”删除已入库内容。

实施前基线（历史）：`app/excel-importer.tsx` 上传后直接调用 `/api/imports/preview`；`lib/standard-import.ts` 只解析名为“语料填写”的一页，其他非允许的有内容页整份拒绝。两种旧适配器能解析其规定的章节页，但没有交互式 Sheet 选择。当时 `ImportPreview` 的 `detailSheets/skippedSheets` 是结果说明，不能当作已实现的选择能力。

本增量包含三种现有格式的选择入口，以及标准模板的多数据页；不包含任意列映射、自动修表/翻译/评级、AI/OCR、跨书合并、上传整本 PDF、逐 Sheet 部分成功、自动导入全部等级或自动加入复习池。一次仍只向一个 Reading 来源导入严格 P1。

## 2. 需求与界面合同

| 编号 | 要求 | 完成标准 |
|---|---|---|
| MS-01 | 工作簿清点 | 显示原顺序、页名、可见性、识别格式/角色、估计数据行数或“待检查”、错误/排除原因；清点不写业务库 |
| MS-02 | 选择范围 | 初始全部不选；支持单选、多选、全选可见数据页、取消全选；至少选择一页才能检查内容 |
| MS-03 | 格式与书籍约束 | 标准数据页可任意命名，但保留 15 列；已选页面必须同模板、同书，选择一个目标来源 |
| MS-04 | 分层校验 | 文件安全限制全局执行；表头/逐行业务错误仅阻止已选页面；明确报页名/行号/字段 |
| MS-05 | 本次文件内去重 | 跨所选页的完整相同记录折叠，内容或义项不同不静默合并；保留可核对的重复位置 |
| MS-06 | 已入库内容对比 | 保留新增/重复/变更/保护/含糊分类及旧键兼容，未选择或未出现的旧内容保留 |
| MS-07 | 状态与凭据 | 文件/范围改变后旧预览、义项选择、差异、修订处理、确认失效；服务端拒绝伪造/过期/跨范围凭据 |
| MS-08 | 写入与回归 | 仅明确确认后全批事务写入；失败、重试和响应丢失不重复增加记录，个人数据/Review 保留 |

### 2.1 清单与“全部”的准确含义

- 初始不选任何页面。按钮使用“全选可见数据页”，旁边显示已选页数、未选数据页数、隐藏页数和排除页数；不能只写“整个 Excel”，让用户误以为说明/示例也入库。
- 全选包含可见且可识别为三种模板之一的数据页，包含已识别但表头残缺的数据候选页；后者被选中时阻止内容预览并明确修正提示，不能悄悄排除后声称全选成功。
- 隐藏和 veryHidden 数据页只展示，不默认或随全选勾选；用户可明确单独勾选。页面顺序沿工作簿顺序，不按用户点击先后或按名称猜测章节顺序。
- 空白页、保留的说明/示例/统计/汇总页、完全无法识别格式的有内容页不可选择，并给原因；不提供绕过格式的“强行导入”。可识别但缺列的数据候选页可选，修正表头后才可继续。
- 页名为 `语料填写` 或含标准标志列 `英文词条` 可识别为标准数据候选；旧两格式沿适配器的标志列/标题及章节角色识别。多个标志冲突时该页标为格式含糊，不自动猜选。
- 角色识别先于数据表头识别：`填写说明`、`填写示例`、`P1 优先掌握`、`P1 去重复习`、`优先级说明与统计` 均按已知辅助页排除，即使带相似列也不导入。用户将真实数据放进这些保留名称时提示改名。普通未知页不靠模糊名称猜成汇总而静默忽略。
- 清点页显示“仅检查页信息，内容尚未通过校验”；估计行数不冒充 P1 数、唯一语境数或最终导入数。没有可选页、已选页无 P1、全部重复分别提供原因；无 P1 不能创建空来源。

### 2.2 预览、对比和返回修改

进入内容预览前完整校验所有已选页，成功后才生成一份覆盖这些页的预览。不允许先预览有效页、悄悄遗漏同批错误页。未选页的缺列、错等级、错误高亮或公式不阻止已选页，但清单保留其未检查/错误状态；这些页没有被视为通过。

预览顶端始终显示本次实际页名、目标书籍、P1/P2/P3 原始行数、文件内重复数、去重后可选 P1 语境数、排除数量。逐组保留 Sheet 和 Excel 行号。展示前校验所选全部有效数据行，包括后续会排除的 P2/P3，不先过滤再隐藏错误。

切换文件、增减 Sheet 或重新清点必须取消旧请求的状态写回，清除旧预览、分组决策、对比、采用新值选择和批量确认，再由新预览重建默认项。仅改目标来源/来源标题/是否独立同名或分组决策时，沿用当前内容预览，但使差异及确认失效。提交处理中锁定范围和文件，不允许并发切换。

存在未提交的文件/范围选择时，离开页面沿用未保存输入提醒；取消离开保留当前状态，明确离开可清理页面内存，不承诺跨路由或刷新自动恢复。错误与网络中断保留当前文件和范围以便重试；新请求开始后不得继续显示可提交的旧结果。进程重启/凭据过期提示重新清点及预览。刷新浏览器后不承诺保留本地 File 对象，需重新选择文件。手机宽度 393px、桌面 1280px、键盘操作均可选择/检查/确认，状态不只靠颜色表达。

## 3. 格式合同和兼容

- 标准模板继续使用现有 15 个列名、含义、长度、高亮定位/原文状态/非原文例句规则，保留 `phrasebud-v1` 格式标识；本轮不创建新业务格式、不自动补章名或原句。列可重排；重复/缺失/未知列仍报错。任意普通页名只表示容器，不改变“章节/页码至少一项”的要求。
- 同一书可有一页“语料填写”或多页 `Chapter 1`、`Chapter 8` 等；旧单页无需改文件。旧两适配器保留原列映射和章节角色/页名限制，不把一个新书的自定义表当作旧书专用格式。
- 仅对所选页检查模板混用：已选页包含多种格式则拒绝；未选的其他格式页只展示，不影响本次范围。此为新选择流程的规则变化，不得借此放开未选择范围的旧接口。
- 标准格式检查已选全部数据行的规范化书名一致性，包含 P2/P3；同名归一规则沿用现有 `normalize`。不是自动按书拆批，不按 Sheet 单独建来源。不包含在所选范围内的其他书页可留在工作簿里。
- 选页或全选都不能推断整本书已读完；复用来源保留现有阅读状态。新选择模式新建书籍来源默认“阅读中”，后续由用户维护；旧模式的历史默认行为不在本轮顺带改写。
- 用户明确选择原有书籍来源；书名不一致时阻止继续并提示核对/更换来源，不自动改名或新建同名副本。旧书专用格式沿其固定作品身份校验；不同版本作品仍需用户明确区分。
- 不再依赖“工作簿有任意额外数据页就全局拒绝”的旧检查来实施新流程，拆成全局文件安全清点与所选页严格业务校验。保留旧 API 的默认整本校验行为，见第 5 节。

## 4. 去重、身份和统计合同

### 4.1 三种身份分别使用

1. **选择页身份**：绑定本次文件原始字节 SHA-256、工作簿中的顺序和精确页名，由服务端清点生成 `sheetId`；用于防止选错页和请求篡改，不直接作为持久去重依据。文件换名不改变其原始字节哈希；内容或分页改动后重新清点。
2. **物理行键**：标准模板新导入的 64 字符十六进制 SHA-256 输入加独立算法域 `sheet-row-v2`，包含格式、规范化书名、精确 Sheet 名、原 Excel 行号、规范化词条、原句、章节和位置。沿用现有 `rowKey` 字段形状，避免不同 Sheet 相同行号撞键；不包含文件名、文件哈希、选页顺序或提交批次。旧两适配器原有已含 Sheet 的键保持不变。
3. **语义接触匹配**：限定所选目标 Source 和同格式，按规范化词条、原句、章节、位置匹配接触候选，再核对完整字段；不以行号、文件名或 Sheet 名漂移本身制造新的真实接触。同词不同句/章节/位置不当作完全重复，同形异义不强合并。

物理行键用于行级凭据区分，不等于唯一义项或唯一真实接触。`ImportRow.key`、差异行键和 `updates` 映射必须保证每个实际待处理条目唯一；合并预览后断言唯一，不能用 Map 覆盖同键行而丢数据。

### 4.2 文件内重复与冲突

- 先校验字段，再对所选 P1 行做文件内比对。只有业务内容完整一致才折叠：同模板、规范化书名和词条、相同中文义项、相同原句/章节/位置/等级，以及高亮、原文状态、释义、例句/译文/来源、搭配、核对备注和其他导入内容相同；文件名/Sheet/行号/派生统计不计入业务内容。沿用既有规范化边界，原句/笔记等不做会丢含义的模糊处理。
- 折叠代表为工作簿顺序最前、行号最小的记录，预览列出所有重复位置、计入文件内跳过数；多选顺序不改变结果。首版无需为副本永久新增语境或数据字段，不将复制的同一原句算作新 Seen。
- 同词但中文义项不同：分别保留分组，沿用人工选择义项。相同接触候选但高亮、备注、例句等内容不同：不得折叠或按最后一个覆盖，报告具体冲突位置并阻止本次预览；用户修表或取消其中一页后再检查。首版不新增一套文件内逐字段合并器。
- 已有库中同形多义仍显示候选，只有唯一同释义有效 P1 默认复用；其他情况用户明确新建/追加/跳过。不以全文本复制自动合并已经存在的独立义项。

### 4.3 兼容旧导入与文件重排

匹配顺序：新物理键 → 兼容旧键且核对内容/原位置/格式/书籍 → 已有的词条/原句/章节/位置候选 → 原页名及行号的唯一修订候选。多候选为含糊项，默认保护，不任选第一条。

旧标准键未含 Sheet，不能把新多页中“恰好算出相同旧键”的行无条件视为同一记录；兼容分支须核对实际旧来源、模板、Sheet/内容身份，若仅 Sheet 改名或移动则走完整接触匹配。首次旧键匹配成功不批量重写旧 Context/指纹/版本或历史。新物理键与旧语义兜底必须覆盖：文件改名、行重排、Sheet 调序/改名、从“语料填写”搬到章节页、只传一页后再全选。

只改分页、行号或文件名时不产生内容变更；若实际词句/位置/释义等改动，则继续按 [24](24-来源去重与增量导入设计及验收.md) 展示差异，默认保留旧值。分页/位置/内容同时大幅改变且无法唯一识别时不承诺自动识别同一次接触，应显示可核对的新增或含糊候选，由用户检查，不能拿旧行号猜覆盖。

新章节遇到同词但不同原句：新增语境并允许追加原义项。未选页、未出现在新文件中的旧记录、归档和回收站资料均保留；不自动恢复归档/删除数据、不升级 P2/P3、不改个人笔记、Expression 义项/等级或已完成 Review 记录。

### 4.4 数量口径

分开显示：已选非空数据行总数、P1/P2/P3 数、P1 文件内重复副本数、唯一 P1 语境数、分组后选中语境数、库对比的新增/重复/变更/保护/含糊数，以及实际新增表达/语境、采用修订、保留旧值和各类跳过数。前者按行，后者按语境/表达，不能混成同一个 N。

应满足：有效数据行总数 = P1 + P2 + P3；P1 = 唯一 P1 语境 + 文件内折叠副本；选中唯一语境数 = 本次库对比中 selected 项的各分类之和。组内跳过、文件内重复、库内重复分别可追溯，不双算。完全重复的再次上传可完成零新增核对，但不创建空来源、不增加 Seen/Used 或 Review。

## 5. 接口与安全合同

新增清点与选择预览模式；不引入服务端永久原始文件存储。客户端当前页面内存保留 File/内容，清点和所选预览分别发送文件；服务端每次执行压缩检查并核对文件身份。没有 AI、OCR、外部表格服务调用或后台自动导入。

| 接口 | 建议输入/输出与约束 |
|---|---|
| `POST /api/imports/inspect` | 接收现有 `fileName/content`；返回文件哈希、清单版本、每页 `sheetId/name/order/state/role/profile/estimatedRows/headerIssues` 和签名 `inspectionToken`；只列页/表头及估计行数，不认证原句正确性 |
| `POST /api/imports/preview` 新模式 | 显式 `mode=selected-sheets-v1`，提交原文件、`inspectionToken`、非空且无重复的 `selectedSheetIds`；服务端重算哈希、顺序和页身份，检查签名/范围再完整验证所选页；输出沿用原预览并增加模式、准确选区、文件内重复位置及统计 |
| `POST /api/imports/diff` | 沿用签名内容预览和来源/分组选择，差异证明绑定内容预览摘要、选区、目标来源/标题/同名决策、义项选择和库状态；选择变化不能复用旧差异 |
| `POST /api/imports/commit` | 只消费服务端签名的所选行、最终选择、有效差异及明确确认；禁止临时传入额外页/行/修改后的字段，重试沿用既有幂等与全批事务 |

`sheetId` 和 `selectedSheetIds` 只表达选择，不由客户端指定读取 XML 路径；服务端仅从已校验工作簿实际页清单查找。空选、重复 ID、不存在/来自其他文件的 ID、辅助页、签名篡改、过期或库 generation/差异状态变化均拒绝，不产生业务写入。

新清点 token 使用独立类型域及版本；新内容预览明确 token 版本、模式、文件哈希、工作簿顺序的精确选页 ID/名称、已验证 P1 行和过期时间，并纳入签名。清点与预览各自有效 30 分钟，二者不互换；进程重启按现有签名机制失效。不能通过前端删除某些预览行而绕过格式检查。新内容预览摘要还须绑定分组数据，跨选区的差异 token 不可提交。

旧 `/preview` 不带 mode 时保留原整工作簿严格检查/解析合同，旧签名内容的解析兼容只能走旧模式，不能隐式当作“任选页”；升级造成旧临时预览不可用时明确要求重新上传，不能无校验兼容。新 UI 必须先清点并显式选择，不设默认选中全部的隐藏分支。

全局限制沿用已实现边界：`.xlsx` ≤5 MB、请求 JSON ≤8 MB、实际总解压 ≤40 MB、压缩目录/条目/实际解压一致性、每页 ≤10,000 行且 ≤100 列。即使危险包或超大页未被选中也不得绕过全局限制。所选非空数据行合计统一 ≤5,000（包含 P2/P3，不能靠分 Sheet 绕过），沿用 ≤1,000 分组、现有 token 尺寸上限；过大给出“减少所选页/行并重新预览”的可操作错误，不截断后声称完整导入。清点最多 1,000 个工作表（同时受原 ZIP 目录最多 2,000 个条目限制），序列化清单响应最多 1 MB；请求/预览 token 仍受上述上限限制，不承诺无限 Sheet。

本机模式沿用 Host/同源 Origin，云端沿用唯一所有者、登录、维护只读和 generation 校验；清点/预览不写 Source、Draft、Expression 或 Context。写入沿 [24](24-来源去重与增量导入设计及验收.md) 事务和更新前快照规则；快照失败/任一页写入失败全批不修改。校验错误不签发可提交预览。

首选保持 SQLite/schema 3 和现有导入 profile/元数据字段；选区/文件内副本位置仅在临时预览展示，不必增加持久字段。新键仍为 SHA-256 的 64 字符十六进制串。不得为方便识别加入未被 `draftSchema`、严格 JSON 备份、详情/回顾快照接受的字段；若开发证明确需扩展，先补充兼容合同及备份往返测试，不直接越过本设计。
